Connect to T3 Code

Choose the endpoint where your T3 Code server is running.

Keep T3 Code open. In T3’s Settings → Connections → Authorized clients, create a pairing code with permission to read threads, then paste it below.

Use your preferred local or remote T3 server address. The desktop app usually starts on port 3773; use the port shown in T3 if it differs. Use HTTPS for remote servers.

The extension requests read-only thread access. A fresh code is required for a new endpoint or to renew an expired connection.
